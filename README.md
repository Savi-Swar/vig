# Vig

My research terminal, served at https://saviturswarup.com/vig/

Seven screens of static HTML regenerated daily by the pipeline in
github.com/Savi-Swar/StrategyBuilder: model desk, analysis, screener, graded
past calls, portfolio, the full research record, and a live paper desk on
prediction markets (ledgers in github.com/Savi-Swar/desk).

This repo is the deploy target, not the source. Nothing here is edited by
hand.
